## ⚡ What Is This?

Welcome to the **Quantum Teleportation & Decoherence Simulator**! 

We take **144 physical qubits** on an IBM Heron superconducting processor, encode the legendary message **`"Rex tests da metal!"`**, and teleport it across time and space. 

Will the message survive the brutal thermal noise of $T_1$ relaxation? Or will quantum decoherence reduce Rex’s grand experiment to ASCII soup? **You control the physics.**

---

## 🔥 Features That Slap

* ⚛️ **144-Qubit Dynamic Teleportation:** Full 8-bit ASCII character encoding running live Bell measurements.
* 🛰️ **Rex → FutureRex Transfer:** Clean register abstraction for sender, entangling channel, and receiver.
* 🛡️ **Quantum Error Correction (QEC) Engine:** Toggle between **Unprotected**, **3-Qubit Repetition**, and **5-Qubit Distance-3** surface codes.
* ⚡ **Dynamical Decoupling (DD):** Fire off simulated XY4 $\pi$-pulse sequences to fight off low-frequency phase noise.
* 📊 **Real-Time Readout & Metrics:** Live binary bitstream visualization, physical error counters, and a fidelity progress bar.
